# منطق موديول المخزون — Nilotic Frost ERP

## نظرة عامة

موديول المخزون يتكون من ثلاثة مستويات متمايزة:
1. **مخزون المادة الخام** — لوطات الخام القادمة من الموردين
2. **مخزون المستلزمات والكراتين** — مواد التعبئة والتغليف
3. **مخزون المنتج الجاهز** — الباتشات الجاهزة للشحن

---

## أولاً: مخزون المادة الخام (Raw Lots)

### هيكل اللوط (Lot)

```javascript
{
  batchId: "LOT-RAW-001",          // معرف فريد
  station: "محطة النخيل",           // المحطة التي استُلم فيها
  rawProduct: "فراولة",              // نوع الخام
  supplierName: "مزارع الوادي",      // المورد
  initialQty: 8000,                  // الكمية الأولية (كجم)
  availableQty: 4000,               // الرصيد المتبقي (يتناقص مع السحب)
  unitCost: 18.50,                   // سعر الكيلو (شامل النقل)
  receivedDate: "2026-08-15",
  qcStatus: "APPROVED",             // حالة الجودة
  brixDegree: 8.5,                  // درجة البريكس
  truckPlate: "أ ب ج 1234"          // لوحة السيارة للتتبع
}
```

### قواعد الرصيد

| الحدث | تأثير على `availableQty` |
|-------|------------------------|
| استلام لوط جديد | يُضاف كاملاً `initialQty` |
| سحب للإنتاج | يُطرح الكمية المسحوبة |
| **لا يمكن الرصيد أن يصبح سالباً** | `Math.max(0, availableQty - usedQty)` |

### بوابة الجودة (QC Gate)

- كل لوط يمر بتفتيش جودة عند الاستلام
- قيم `qcStatus`: `APPROVED` | `REJECTED` | `PENDING`
- في البروتوتايب: جميع اللوطات الموجودة `APPROVED`
- **[فجوة]:** منطق رفض اللوطات غير مطبّق في الكود (لا إجراء للـ `REJECTED`)

## ثانياً: مخزون المستلزمات (Supplies)

### هيكل المستلزم

```javascript
{
  id: "SUP-01",
  code: "CTN-EXP-10K",
  name: "كرتونة تصدير 10 كجم (5 طبقات)",
  category: "كرتونة",           // أنواع: كرتونة / أكياس / بالتات / لاصق / تغليف
  capacityKg: 10,               // سعة الكرتونة بالكجم
  unit: "كرتونة",
  stock: 2020,                   // الرصيد الحالي
  unitPrice: 18.00               // سعر الوحدة (ج.م)
}
```

### تحديث رصيد المستلزمات

| الحدث | تأثير على `stock` |
|-------|-----------------|
| استلام شراء جديد | `stock += qty` |
| استهلاك في عملية إنتاج (consumed) | `stock -= consumed` |
| هالك مستلزمات (waste) | `stock -= waste` |
| **المسحوب الفعلي** | `withdrawn = consumed + waste` |

## ثالثاً: مخزون المنتج الجاهز (Finished Goods Batches)

### هيكل الباتش

```javascript
{
  fgBatchId: "FG-PR-2026-001",       // معرف الباتش
  sourceType: "MANUFACTURED",         // MANUFACTURED أو DIRECT_PURCHASE
  sourceOpId: "PR-2026-001",          // رقم عملية الإنتاج (إذا MANUFACTURED)
  station: "محطة النخيل",
  productName: "فراولة مجمدة IQF",
  productionDate: "2026-08-21",
  initialQty: 4800,                   // الكمية الأولية (كجم)
  availableQty: 4800,                 // الرصيد المتبقي
  costPerKg: 31.56,                   // التكلفة الموزونة للكيلو
  totalValue: 151500,                 // إجمالي القيمة (ج.م)
  rawSources: [...],                  // شجرة مصادر الخام (للتتبع)
  suppliersSummary: [...]             // ملخص حصة كل مورد
}
```

### نوعا الباتشات

| النوع | الوصف | رقم البادئة |
|------|-------|------------|
| `MANUFACTURED` | ناتج عملية إنتاج داخلية | `FG-PR-XXXX` |
| `DIRECT_PURCHASE` | واردة كصفقة جاهزة | `FG-DIR-XXXX` |

### تخفيض رصيد الباتش

```javascript
// عند إنشاء الشحنة
fg.availableQty -= allocQty;
// التحقق: إذا allocQty > fg.availableQty → خطأ
```

## إدارة المخازن (Warehouses)

في البروتوتايب، كل محطة تمتلك:
- **مخزن الخام:** يستوعب اللوطات الواردة
- **مخزن الجاهز:** يستوعب الباتشات التامة الصنع
- **مخزن المستلزمات:** كراتين وتغليف

### التحويل بين المحطات (Inter-Station Transfer)

```javascript
{
  transferId: "TRF-2026-001",
  fromStation: "محطة النخيل",
  toStation: "محطة السلام",
  batchId: "FG-PR-2026-001",
  qtyKg: 1000,
  status: "تم الاستلام بنجاح"
}
```

> **ملاحظة:** في الكود الحالي، عند التحويل يتم خصم `qty` ثم إضافتها مجدداً (bug مشتبه به — انظر `02-analysis/gaps-and-open-questions.md`)

## حركات المخزون (Stock Movements)

أنواع الحركات المسجّلة:

| نوع الحركة | الوصف |
|-----------|-------|
| **استلام خام (Raw Receipt)** | وصول لوط من مورد |
| **استلام مستلزمات (Supply Receipt)** | وصول كراتين وتغليف |
| **استلام جاهز (FG Receipt - Direct)** | وارد بضاعة جاهزة |
| **سحب للإنتاج (Withdrawal - Production)** | سحب خام لعملية إنتاج |
| **إنتاج جاهز (FG Production)** | إنشاء باتش جديد |
| **تخصيص شحنة (Allocation)** | حجز من باتش لشحنة |
| **تحويل بين محطات (Transfer)** | نقل كمية بين محطتين |
| **تسوية (Adjustment)** | تصحيح رصيد يدوي |

## مراقبة الهالك (Waste Monitoring)

### معادلة الهالك

```
هالك الخام = إجمالي الخام المدخل - الناتج الجاهز - الناتج الثانوي
نسبة الهالك % = (هالك الخام ÷ إجمالي الخام المدخل) × 100
```

### المعيار الافتراضي لكل منتج

| المنتج | نسبة الهالك المعيارية | نسبة الإنتاجية |
|-------|---------------------|---------------|
| فراولة مجمدة IQF | 20% | 80% |
| فراولة شرائح مجمدة | 22% | 78% |
| مانجو مكعبات مجمدة | 28% | 72% |
| بامية ممتازة مجمدة | 15% | 85% |

### أنواع الهالك

1. **هالك الخام:** كجم ضائع من المادة الأولية (قشور، مرفوض)
2. **هالك المستلزمات:** كراتين أو أكياس تالفة خلال التعبئة

### تتبع الهالك

كل هالك مرتبط بـ:
- عملية إنتاج محددة (PR-XXXX)
- محطة محددة
- لوط خام محدد → مورد محدد
