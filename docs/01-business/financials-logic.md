# منطق موديول الماليات والمحاسبة — Nilotic Frost ERP

## نظرة عامة

الموديول المالي يعمل كـ **دفتر أستاذ موحد (Unified General Ledger)** يسجّل كل حركة مالية ناتجة عن العمليات تلقائياً أو يدوياً.

---

## أنواع القيود المالية (Transaction Types)

| النوع | الاتجاه | يُنشأ تلقائياً عند؟ |
|------|-------|-----------------|
| `استحقاق توريد خام (AP)` | خروج | تسجيل لوط خام |
| `استحقاق توريد مستلزمات (AP)` | خروج | شراء مستلزمات |
| `استحقاق شراء صفقة جاهزة (AP)` | خروج | شراء بضاعة جاهزة |
| `استحقاق تشغيل وفرز (AP)` | خروج | اعتماد عملية إنتاج |
| `استحقاق مبيعات تصدير (AR)` | دخول | اعتماد شحنة تصدير |
| `سند تحصيل دفعة (Inflow)` | دخول | إضافة يدوية (تحصيل من عميل) |
| `سند سداد دفعة (Outflow)` | خروج | إضافة يدوية (سداد لمورد) |

## هيكل القيد المالي (Financial Transaction Record)

```javascript
{
  txnId: "TXN-2026-001",
  date: "2026-08-15",
  type: "استحقاق توريد خام (AP)",
  partyType: "مورد خام",                  // عميل تصدير / مورد خام / مقاول / محطة
  partyName: "مزارع الوادي الحديثة",
  amountEgp: 148000.00,
  amountCurrency: 7400.00,                // قيمة بالعملة الأجنبية (للصفقات الدولية)
  currency: "EUR",                        // العملة الأجنبية
  refDoc: "LOT-RAW-001",                  // المستند المرجعي
  description: "استحقاق توريد 8,000 كجم فراولة خام",
  accountId: "ACC-01",                    // الحساب البنكي/الخزينة
  accountName: "البنك التجاري الدولي CIB",
  status: "معتمد"                         // معتمد / مسدد / معلق
}
```

## الأرصدة المحاسبية

### حساب رصيد العميل

```javascript
getCustomerBalance(customerName):
  الإيرادات = Σ TXN [partyName = customerName, type includes "استحقاق مبيعات"]
  التحصيلات = Σ TXN [partyName = customerName, type includes "تحصيل" OR "Inflow"]
  الرصيد المستحق = الإيرادات - التحصيلات
```

> رصيد موجب = العميل يدين لنا بهذا المبلغ (ذمم مدينة AR)

### حساب رصيد المورد

```javascript
getSupplierBalance(supplierName):
  المستحق = Σ TXN [partyName = supplierName, type includes "استحقاق"]
  المدفوع = Σ TXN [partyName = supplierName, type includes "سداد" OR "Outflow"]
  الرصيد المستحق = المستحق - المدفوع
```

> رصيد موجب = نحن ندين له بهذا المبلغ (ذمم دائنة AP)

### حساب رصيد المقاول

```javascript
getContractorBalance(contractorName):
  المستحق = Σ TXN [type includes "استحقاق تشغيل"]
  المدفوع = Σ TXN [type includes "سداد" OR "Outflow"]
  الرصيد = المستحق - المدفوع
```

## إجماليات الوضع المالي

### الدالة: `ERPState.getFinancialStatementsTotals()`

```javascript
{
  totalReceivables,    // Σ أرصدة العملاء الموجبة (المستحق لنا)
  totalPayables,       // Σ أرصدة الموردين + المقاولين (المستحق علينا)
  totalCollections,    // Σ كل التحصيلات المقبوضة
  totalPayments,       // Σ كل المدفوعات الصادرة
  totalRevenues,       // Σ إيرادات الشحنات
  totalCOGS,          // Σ تكاليف الشحنات
  grossProfit,         // totalRevenues - totalCOGS
  netCashFlow          // totalCollections - totalPayments
}
```

## الخزينة والبنوك (Treasury Accounts)

### هيكل الحساب

```javascript
{
  id: "ACC-01",
  name: "البنك التجاري الدولي CIB (EUR)",
  currency: "EUR",
  balance: 45000.00,
  accountNo: "100029384812"
}
```

### الحسابات الافتراضية

| المعرّف | الاسم | العملة | الرصيد الأولي |
|--------|------|-------|------------|
| ACC-01 | البنك التجاري الدولي CIB | EUR | 45,000 EUR |
| ACC-02 | بنك قطر الوطني QNB | EGP | 1,450,000 ج.م |
| ACC-03 | خزينة المحطة المركزية | EGP | 125,000 ج.م |

### تحديث رصيد الحساب

```javascript
// عند التحصيل (Inflow):
account.balance += amount;

// عند السداد (Outflow):
account.balance -= amount;
```

## نموذج إضافة حركة مالية يدوية (add-transaction.html)

### حقول النموذج

| الحقل | القيم المتاحة |
|-------|-------------|
| نوع العملية | سداد (Payment) / تحصيل (Collection) |
| نوع الطرف | مورد / عميل / مقاول / محطة |
| اسم الطرف | اختيار من القائمة |
| الرصيد المستحق الحالي | يُعبأ تلقائياً (معاينة) |
| المبلغ | إدخال يدوي |
| الخزينة / البنك | اختيار الحساب |
| طريقة الدفع | تحويل بنكي / شيك / نقدي |
| التاريخ | إدخال |
| المستند المرجعي | رقم فاتورة أو مستند |
| ملاحظات | اختياري |

### معادلة معاينة الرصيد (Live Balance Preview)

```
الرصيد الجديد = الرصيد الحالي + المبلغ   (للتحصيل)
الرصيد الجديد = الرصيد الحالي - المبلغ   (للسداد)
```

هذه المعادلة تُحدَّث مباشرة في الواجهة عند تغيير المبلغ.

## كشف حساب الطرف (party-statement-details.html)

يعرض لكل طرف:
- تاريخ كل قيد
- المستند المرجعي
- المبلغ المستحق (مدين/دائن)
- الرصيد التراكمي (Running Balance)
- إمكانية تصدير وطباعة الكشف

---

## المدفوعات والتحصيلات (payments-collections.html)

يعرض جدولاً بكل الحركات النقدية الفعلية (الـ Inflow والـ Outflow) مع:
- فلترة حسب نوع الطرف، التاريخ، الحساب البنكي
- إجماليات المقبوض والمدفوع
- رابط لتفاصيل كل حركة

---

## القيود الأوتوماتيكية مقابل اليدوية

| نوع القيد | طريقة الإنشاء |
|---------|-------------|
| استحقاقات الشراء (AP) | تلقائي عند تسجيل الشراء |
| استحقاقات المبيعات (AR) | تلقائي عند اعتماد الشحنة |
| أتعاب المقاول | تلقائي عند إقفال الإنتاج |
| سندات التحصيل/السداد | يدوي من شاشة add-transaction |

---

## تحويل العملات

```
الإيراد بالجنيه = الكمية (كجم) × سعر البيع (EUR) × سعر الصرف
مثال: 4000 × 1.85 × 53.20 = 393,680 ج.م
```

> سعر الصرف يُدخَل يدوياً في الطلبية ويُورَث للشحنة. لا يوجد استدعاء تلقائي لسعر صرف لحظي.
