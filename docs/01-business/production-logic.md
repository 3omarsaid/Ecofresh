# منطق موديول الإنتاج والتدوير — Nilotic Frost ERP

## نظرة عامة

عملية الإنتاج هي التحويل من **خام → منتج جاهز** عبر خط التدوير في المحطة. هي أكثر العمليات تعقيداً في النظام وتربط: الموردون ← الخام ← المستلزمات ← المحطة ← المقاول ← الجاهز.

---

## الدالة المسؤولة: `ERPState.createProcessingOperation(opData)`

---

## خطوات العملية (Workflow)

```
1. اختيار المحطة
2. تحديد نوع الخام والمنتج الجاهز المراد إنتاجه
3. سحب لوطات الخام المطلوبة (rawIssues)
4. سحب المستلزمات المطلوبة (suppliesIssues)
5. إدخال الناتج الجاهز (كجم)
6. احتساب التكلفة الكاملة
7. اعتماد العملية وإقفالها (LOCK)
    ↓ يشغّل تلقائياً:
    ├── خصم كميات الخام من اللوطات
    ├── خصم المستلزمات من الرصيد
    ├── إنشاء باتش جاهز FG-PR
    └── إنشاء قيد AP للمقاول
```

## معادلات الإنتاج

### 1. معادلة الهالك

```
هالك الخام = إجمالي الخام المدخل - الناتج الجاهز - الناتج الثانوي
هالك الخام = 6000 - 4800 - 300 = 900 كجم

نسبة الإنتاجية (Yield) = (الناتج الجاهز ÷ إجمالي الخام) × 100
نسبة الإنتاجية = (4800 ÷ 6000) × 100 = 80%
```

### 2. معادلة تكلفة الخام

```
تكلفة الخام الكلية = Σ (كمية كل لوط × سعر كيلو اللوط)
مثال: (4000 × 18.50) + (2000 × 19.20) = 74,000 + 38,400 = 112,400 ج.م
```

### 3. معادلة تكلفة المستلزمات

```
تكلفة الاستهلاك = الكمية المستهلكة × سعر الوحدة
تكلفة الهالك = الكمية الهالكة × سعر الوحدة
المسحوب الإجمالي = استهلاك + هالك
```

### 4. معادلة أتعاب المقاول

```
أتعاب المقاول = الناتج الجاهز (كجم) × سعر المقاول لكل كجم
مثال: 4800 × 2.00 = 9,600 ج.م
```

> المقاول يُدفع له على الكيلو **الجاهز** وليس الخام.

### 5. معادلة رسوم المحطة

```
رسوم المحطة = الناتج الجاهز × سعر الكيلو للمحطة
مثال: 4800 × 2.50 = 12,000 ج.م (افتراضي إذا لم يُحدد)
```

### 6. معادلة التكلفة الإجمالية

```
الإجمالي = خام + استهلاك مستلزمات + هالك مستلزمات + مقاول + محطة + أخرى
الإجمالي = 112,400 + 14,400 + 600 + 9,600 + 12,000 + 2,500 = 151,500 ج.م
```

### 7. تكلفة الكيلو الموزونة (Weighted Average Cost/kg)

```
تكلفة الكيلو = إجمالي التكلفة ÷ الكيلو الجاهز
تكلفة الكيلو = 151,500 ÷ 4,800 = 31.56 ج.م/كجم
```

> هذه القيمة تنتقل للباتش الجاهز وتُستخدم في حساب تكلفة الشحنة لاحقاً.

## سحب الخام من اللوطات (Raw Issues)

لكل لوط مسحوب:
```javascript
batch.availableQty = Math.max(0, batch.availableQty - usedQty);
```
> الكمية المسحوبة لا تعود للوط — لا يوجد إلغاء جزئي في البروتوتايب.

عند اعتماد العملية يُنشأ باتش جاهز تلقائياً:

```javascript
  initialQty: 4800,
  availableQty: 4800,

    { supplierName: "مزارع الوادي", sharePct: 66.7 },
    { supplierName: "شركة الخير",   sharePct: 33.3 }

```

## الآثار التلقائية عند إقفال العملية (LOCK)

| الأثر | التفاصيل |
|------|---------|
| خصم لوطات الخام | `rawBatch.availableQty -= usedQty` لكل لوط |
| خصم المستلزمات | `supply.stock -= (consumed + waste)` |
| إنشاء باتش جاهز | سجل جديد في `finishedGoodsBatches` |
| قيد AP للمقاول | `TXN = "استحقاق تشغيل وفرز (AP)"` |
| سجل تدقيق | يُحفظ في `audit[]` مع اسم المستخدم والوقت |

|---------|------------------|
| إنشاء عملية جديدة | Admin, Supervisor, Operator, Storekeeper |

| قراءة العمليات | الكل |

---

## إقفال العملية (Locked)

بعد الإقفال: `locked: true`
- **لا يمكن تعديل بيانات العملية**
- **لا يمكن استعادة الخام المسحوب**
- في البروتوتايب: كل العمليات مُقفلة تلقائياً عند الحفظ

## شاشة عمليات التشغيل (processing-operations.html)

### مؤشرات KPI في الشاشة

- إجمالي عدد العمليات
- إجمالي الخام المسحوب (كجم)
- إجمالي الناتج الجاهز (كجم)
- متوسط نسبة الإنتاجية (Yield %)
- إجمالي الهالك (كجم)
- إجمالي التكلفة (ج.م)

### نموذج إضافة عملية جديدة

Modal منبثق يحتوي على:
1. اختيار المحطة → يحمّل المقاول الافتراضي وسعره
2. اختيار الخام والمنتج الجاهز المستهدف
3. سحب لوطات (يمكن سحب أكثر من لوط)
4. إضافة مستلزمات واستهلاكها وهالكها
5. إدخال الكيلو الجاهز الفعلي
6. عرض التكلفة المحسوبة
7. اعتماد وإقفال

---

## تتبع الناتج الثانوي (Secondary Output)

بعض العمليات تنتج:
- **ناتج رئيسي:** المنتج المجمد الجاهز
- **ناتج ثانوي:** قشور/عيش/بذور تباع للمصانع (مثال: 300 كجم قشور مانجو)

الناتج الثانوي لا يُضاف لمخزون الجاهز لكنه يدخل في معادلة الهالك:
```
هالك الخام الفعلي = المدخل - الرئيسي - الثانوي
```
