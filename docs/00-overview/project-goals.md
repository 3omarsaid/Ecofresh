# أهداف المشروع — Nilotic Frost ERP

## ما المشكلة التي يحلّها هذا النظام؟

**Nilotic Frost ERP** هو نظام ERP متخصص لشركات تصدير الأغذية المجمدة المصرية. يعالج الإشكاليات التشغيلية والمحاسبية التالية:

### المشاكل الحالية التي يحلها النظام

| المشكلة | الحل الذي يقدمه النظام |
|--------|----------------------|
| عدم القدرة على تتبع المواد الخام من المزارع حتى الحاوية المصدَّرة | شجرة تتبع كاملة: مزارع المورد → لوط الخام → عملية الإنتاج → باتش الجاهز → الشحنة |
| صعوبة احتساب التكلفة الفعلية للكيلو جرام المنتج | معادلة تكلفة تلقائية: تكلفة الخام + تكلفة المستلزمات + أتعاب المقاول + رسوم المحطة + مصاريف أخرى |
| التحصيل من العملاء الدوليين وسداد الموردين غير مرتبطَيْن بالعمليات | دفتر حسابات مركزي يربط كل عملية (شحنة/شراء/إنتاج) بقيد مالي تلقائي |
| تسجيل الهالك يدوياً دون تحليل أسبابه | مركز مراقبة الهالك 360° مع تصنيف حسب محطة/مورد/منتج |
| غياب تقارير ربحية الشحنات لاتخاذ قرارات تسعيرية | جدول ربحية تفصيلي بهامش صافي لكل شحنة |

## لمن هو هذا النظام؟

- **الشريحة الرئيسية:** شركات التصدير المصرية للأغذية المجمدة (فراولة، مانجو، خضار)
- **حجم الشركة المستهدف:** شركات متوسطة إلى كبيرة تمتلك من 2 إلى 10 محطات تبريد وتجميد
- **جغرافيا العمل:** العمليات في مصر، التصدير لأوروبا والخليج

## لماذا هذا النظام مختلف؟

1. **مصمم خصيصاً للتجميد والتصدير:** يفهم مفاهيم اللوطات، الهالك، معدلات الإنتاج، وشروط FOB/CIF
2. **يدعم العربية RTL بالكامل:** واجهة عربية أصيلة، مش مجرد ترجمة
3. **ربط عمليات ←→ مالية تلقائي:** أي عملية تشغيل أو شحنة تولّد قيود مالية فوراً
4. **تتبع الموردين داخل كل شحنة:** يعرف كل عميل خارجي من أي مزرعة جاءت بضاعته

## النطاق الوظيفي (Functional Scope)

```
الحلقة الكاملة:
مزارع → شراء خام → تخزين لوط → إنتاج/تدوير → مخزون جاهز → طلبية عميل → شحنة تصدير
         ↓                                                                      ↓
    قيد مستحق مورد                                              قيد إيراد + احتساب ربح
```

### موديولات النظام الست الرئيسية

1. **البيانات الأساسية (Master Data):** المنتجات، المستلزمات، العملاء، الموردون، المحطات، المقاولون
2. **العمليات والتشغيل (Operations):** شراء الخام، شراء المستلزمات، إنتاج/تدوير، شراء صفقات جاهزة، طلبيات العملاء، الشحنات
3. **المخزون والتتبع (Inventory & Traceability):** مخزون الجاهز، مخزون الخام، مخزون المستلزمات، المخازن، الهالك
4. **الماليات والتحصيلات (Financials):** كشوف حسابات، مدفوعات/تحصيلات، خزينة/بنوك
5. **التقارير التحليلية (Analytics):** ربحية الشحنات، مراقبة المحطات، تقارير الموردين/العملاء
6. **الموظفون (HR):** سجلات الموظفين (موديول أساسي، غير مكتمل حالياً)

## الحالة الحالية للبروتوتايب

هذا النظام هو **بروتوتايب UI تفاعلي كامل** (40+ شاشة) مع:
- **حالة البيانات:** تخزين في `localStorage` بالمتصفح (لا قاعدة بيانات حقيقية)
- **الحسابات والمنطق:** مُنفَّذان في JavaScript (Client-side فقط)
- **الجاهزية للإنتاج:** يحتاج Backend + قاعدة بيانات حقيقية + API layer
