# قاموس المصطلحات — Nilotic Frost ERP

## المصطلحات التقنية (Technical Terms)

| المصطلح | التعريف |
|---------|--------|
| **ERP** | Enterprise Resource Planning — نظام تخطيط موارد المؤسسة الذي يربط جميع وظائف الشركة في منظومة واحدة |
| **RBAC** | Role-Based Access Control — نظام التحكم في الوصول بناءً على الدور الوظيفي |
| **localStorage** | تخزين محلي في المتصفح يستخدمه البروتوتايب لحفظ البيانات (لا قاعدة بيانات حقيقية) |
| **ERPState** | الكائن الرئيسي في `state.js` المسؤول عن تحميل وحفظ وتعديل كل بيانات النظام |
| **Tailwind CSS** | إطار عمل CSS utility-first مستخدم لتصميم الواجهة وتنسيق المكونات |
| **shadcn/ui** | منظومة مكونات واجهة مستخدم مفتوحة مبنية على Radix UI و Tailwind CSS، تمنح ملكية كاملة للكود وإمكانية وصول قياسية ودعم RTL أصيل |
| **Radix UI** | مكتبة مكونات أولية (Headless Primitives) غير منسقة تركز على إمكانية الوصول WAI-ARIA والتنقل السلس عبر لوحة المفاتيح |
| **RTL** | Right-To-Left — اتجاه الكتابة من اليمين لليسار (العربية) — كل الصفحات `dir="rtl"` |
| **IBM Plex Sans Arabic** | الخط الرسمي للنظام، يدعم العربية والإنجليزية |
| **Lucide Icons** | مكتبة أيقونات تفاعلية عصرية منسجمة تماماً مع مكونات shadcn/ui |
| **Toast Notification (Sonner)** | رسائل التنبيه المنبثقة التفاعلية الحديثة المتوافقة مع shadcn والداعمة لـ RTL |
| **AP** | Accounts Payable — مستحقات مالية علينا (للموردين والمقاولين) |
| **AR** | Accounts Receivable — مستحقات مالية لنا (من العملاء) |

## مصطلحات بيزنس التصدير

| المصطلح | التعريف |
|---------|--------|
| **IQF** | Individual Quick Freezing — طريقة تجميد سريع للحبات منفردةً (الفراولة IQF = حبات كاملة مجمدة) |
| **FOB** | Free On Board — بند تسليم: الشركة مسؤولة حتى الميناء فقط، العميل يتحمل شحن البحر |
| **CIF** | Cost, Insurance, Freight — بند تسليم: الشركة تتحمل التكلفة + التأمين + شحن البحر |
| **LC** | Letter of Credit — اعتماد مستندي: ضمان بنكي من عميل يكفل الدفع عند الشحن |
| **سعر الصرف (FX Rate)** | سعر تحويل العملة الأجنبية (EUR/USD) إلى الجنيه المصري المستخدم لاحتساب الإيراد |
| **بوليصة الشحن (BL)** | Bill of Lading — وثيقة شحن بحري تثبت ملكية البضاعة |
| **الحاوية (Container)** | وحدة الشحن البحري، الشحنة تُصدَّر في حاوية واحدة بكود مميز |
| **ميناء الإسكندرية** | الميناء المصري الرئيسي للتصدير المذكور في البروتوتايب |

## مصطلحات عمليات التجميد والإنتاج

| المصطلح | التعريف |
|---------|--------|
| **لوط/لوطة (Lot/Batch)** | دفعة متجانسة من المواد الخام تأتي من مورد واحد في يوم واحد، لها رقم مميز `LOT-RAW-XXX` |
| **باتش (Batch)** | دفعة من المنتج الجاهز ناتجة عن عملية إنتاج واحدة، رقمها `FG-PR-XXXX` أو `FG-DIR-XXXX` |
| **الهالك (Waste)** | الكمية الضائعة خلال التشغيل (فرز مرفوض، قشور، فائض تبريد)، تُقاس كنسبة مئوية |
| **نسبة الهالك (Waste %)** | `هالك الخام ÷ الخام المدخل × 100` — مثال: 6000 كجم خام → 4800 كجم جاهز → هالك 20% |
| **نسبة الإنتاجية (Yield %)** | عكس الهالك: `الناتج الجاهز ÷ الخام المدخل × 100` — مثال: 4800 ÷ 6000 = 80% |
| **درجة بريكس (Brix Degree)** | مقياس تركيز السكر في الفاكهة، يُستخدم في فحص الجودة (QC) عند الاستلام |
| **درجة أولى** | تصنيف الجودة الأعلى للمنتج المطابق للمواصفات التصديرية |
| **التدوير** | عملية معالجة الخام: فرز + تنظيف + تقطيع + تجميد IQF + تعبئة في كراتين |
| **سحب خام** | إجراء نقل الخام من اللوط المخزون لاستخدامه في عملية إنتاج |

## مصطلحات مالية متخصصة

| المصطلح | التعريف |
|---------|--------|
| **استحقاق توريد خام (AP)** | قيد مالي يُنشأ تلقائياً عند استلام لوط خام، يعني "نستحق للمورد" هذا المبلغ |
| **استحقاق مبيعات (AR)** | قيد مالي يُنشأ عند شحن الحاوية، يعني "العميل يستحق لنا" هذا المبلغ |
| **سند تحصيل (Inflow)** | قيد يسجل استلام مبلغ نقدي من عميل في الخزينة/البنك |
| **سند سداد (Outflow)** | قيد يسجل دفع مبلغ نقدي لمورد أو مقاول من الخزينة/البنك |
| **الرصيد المتراكم** | مجموع الاستحقاقات ناقص المدفوعات لطرف معين |
| **هامش الربح (Margin %)** | `(الإيراد - إجمالي التكلفة) ÷ الإيراد × 100` |
| **التكلفة الكاملة للشحنة** | إنتاج + شحن بري + شحن بحري + جمارك + شهادات + رسوم ميناء |
| **COGS** | Cost of Goods Sold — تكلفة البضاعة المباعة |

## مصطلحات الكيانات الأساسية (Entity Terms)

| المصطلح | التعريف |
|---------|--------|
| **CUST-XXX** | معرّف العميل، مثال: `CUST-001` = شركة سما (هولندا) |
| **SUPP-XXX** | معرّف المورد، مثال: `SUPP-001` = مزارع الوادي الحديثة |
| **STN-XX** | معرّف المحطة، مثال: `STN-01` = محطة النخيل |
| **CONT-XXX** | معرّف المقاول، مثال: `CONT-001` = مقاول أحمد |
| **LOT-RAW-XXX** | رقم لوط المادة الخام |
| **FG-PR-XXXX** | رقم باتش المنتج الجاهز الناتج عن إنتاج داخلي |
| **FG-DIR-XXXX** | رقم باتش المنتج الجاهز الوارد كصفقة مباشرة |
| **ORD-XXXX** | رقم طلبية عميل |
| **SHP-XXXX** | رقم شحنة تصدير |
| **TXN-XXX** | رقم قيد مالي |
| **PR-XXXX** | رقم عملية إنتاج/تدوير |
| **DEAL-XXXX** | رقم صفقة بضاعة جاهزة |
| **TRF-XXXX** | رقم إذن تحويل بين المحطات |
| **ACC-XX** | رقم حساب خزينة/بنك |
