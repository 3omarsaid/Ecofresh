# قاموس البيانات — Nilotic Frost ERP

> هذا الملف يشرح المعنى البيزنسي لكل عمود مهم — ليس فقط نوع البيانات.

---

## كيانات الجداول وشرح الحقول

### raw_batches — لوط المادة الخام

| العمود | الشرح البيزنسي |
|-------|-------------|
| `batch_id` | رقم اللوط الفريد. يُولَّد تلقائياً بصيغة `LOT-RAW-YYYYMMDD-NN`. هو مفتاح التتبع الكامل من المزرعة حتى الشحنة. |
| `initial_qty` | الوزن الصافي للخام بعد طرح وزن المركبة. هذا هو الوزن الفعلي المستلَم والمدفوع عنه. |
| `available_qty` | ما تبقى من هذا اللوط ولم يُستخدَم بعد. يتناقص عند كل عملية إنتاج تسحب منه. عندما يصبح 0، اللوط مُستنفَد. |
| `unit_cost` | تكلفة الكيلو الموزونة = (الكمية × السعر + تكلفة النقل) ÷ الكمية. هذه القيمة تنتقل لحساب تكلفة الإنتاج وبالتالي ربح الشحنة. |
| `qc_status` | نتيجة فحص الجودة عند الاستلام. APPROVED = مقبول للتشغيل، REJECTED = مرفوض ويُعاد، PENDING = قيد الفحص. |
| `brix_degree` | درجة تركيز السكر الطبيعي في الفاكهة. فراولة: 7-9 Brix جيد. مانجو: 14+ Brix جيد. مقياس لجودة المذاق. |
| `truck_plate` | لوحة السيارة للتتبع اللوجستي وتسوية النزاعات مع الموردين. |

### processing_operations — عمليات الإنتاج

| العمود | الشرح البيزنسي |
|-------|-------------|
| `raw_input_kg` | إجمالي الخام المدخل لخط الإنتاج من كل اللوطات المسحوبة في هذه العملية. |
| `finished_output_kg` | الكيلو الجاهز الفعلي الخارج من خط الإنتاج بعد الفرز والتجميد والتعبئة. |
| `secondary_output_kg` | ناتج ثانوي مثل قشور الفاكهة التي تُباع أحياناً للمصانع. لا يُضاف للمخزون الجاهز. |
| `raw_waste_kg` | الفرق بين المدخل والمخرج: `raw_input - finished_output - secondary_output`. يمثّل الضياع الحتمي في الإنتاج (مياه، تالف، غير مطابق). |
| `yield_percent` | `(finished_output ÷ raw_input) × 100`. كلما ارتفعت هذه النسبة، كان الإنتاج أكفأ والتكلفة أقل. |
| `contractor_cost` | أتعاب مقاول العمالة = `finished_output_kg × contractor.tariff_rate_per_kg`. يُدفع على أساس الكيلو الجاهز وليس الخام. |
| `station_cost` | رسوم استخدام المحطة للتجميد والتبريد والبنية التحتية = `finished_output_kg × station.electricity_rate_per_kg`. |
| `cost_per_kg` | تكلفة إنتاج الكيلو الواحد النهائي = `grand_total_cost ÷ finished_output_kg`. هذه القيمة تنتقل للباتش الجاهز وتحدد أدنى سعر بيع مربح. |
| `locked` | بعد الإقفال لا يمكن تعديل العملية. يمنع التلاعب في أرقام التكلفة بأثر رجعي. |

### finished_goods_batches — الباتشات الجاهزة

| العمود | الشرح البيزنسي |
|-------|-------------|
| `fg_batch_id` | رقم الباتش الجاهز. إذا بدأ بـ `FG-PR` = ناتج إنتاج. إذا بدأ بـ `FG-DIR` = واردة كصفقة جاهزة مباشرة. |
| `source_type` | `MANUFACTURED` = مُنتَج في محطة. `DIRECT_PURCHASE` = مشتراة جاهزة من مورد خارجي. |
| `source_op_id` | يربط الباتش بعملية الإنتاج التي أنتجته — مفتاح التتبع العكسي للموردين. |
| `available_qty` | الكمية المتاحة للتخصيص في شحنات جديدة. تتناقص عند كل شحنة. عندما = 0، الباتش مُشحَّن بالكامل. |
| `cost_per_kg` | تكلفة الكيلو المجمّدة عند إنشاء الباتش — لا تتغير حتى لو تغيرت أسعار الخام لاحقاً (تكلفة تاريخية). |

### shipments — الشحنات التصديرية

| العمود | الشرح البيزنسي |
|-------|-------------|
| `container_no` | رقم الحاوية البحرية — مرجع أساسي مع العميل وشركة الشحن وسلطات الجمارك. |
| `seal_no` | رقم ختم الحاوية — يُثبت أن الحاوية لم تُفتح منذ الإغلاق. |
| `inland_trucking` | تكلفة نقل الحاوية من المحطة للميناء. |
| `ocean_freight` | تكلفة الشحن البحري من ميناء الإسكندرية لميناء الوصول. |
| `customs_clearance` | رسوم التخليص الجمركي والوثائق (شهادة منشأ، فاتورة جمركية...). |
| `inspection_certificates` | تكلفة شهادات الفحص والتحليل المطلوبة (شهادة صحية، HACCP، بيطري...). |
| `gross_revenue_egp` | `shipped_qty × unit_price_eur × fx_rate`. الإيراد قبل خصم أي تكاليف. |
| `net_profit_egp` | `gross_revenue - total_shipment_cost`. هامش الربح الصافي من هذه الشحنة. |
| `margin_percent` | `(net_profit ÷ gross_revenue) × 100`. يُستخدم لمقارنة ربحية الشحنات. |

### financial_transactions — القيود المالية

| العمود | الشرح البيزنسي |
|-------|-------------|
| `type` | يحدد طبيعة القيد: هل هو استحقاق (يُعرِّف دين) أو سداد/تحصيل (يسوّي الدين). |
| `party_type` | نوع الطرف الآخر في المعاملة: عميل (AR) أو مورد/مقاول (AP). |
| `amount_egp` | المبلغ بالجنيه المصري — العملة الرسمية للمحاسبة المصرية. |
| `amount_currency` | المبلغ بالعملة الأجنبية — للمراجعة والمقارنة مع فواتير العملاء. |
| `ref_doc` | رقم المستند المرجعي (LOT-RAW-XXX أو SHP-XXX أو PR-XXX). يربط القيد بالعملية التشغيلية. |
| `status` | `معتمد` = ذمة مستحقة (لم تُسدَّد). `مسدد` = سدادات وتحصيلات فعلية. |

### customers — العملاء

| العمود | الشرح البيزنسي |
|-------|-------------|
| `destination_port` | ميناء وصول البضاعة. يُستخدم في وثائق الشحن والجمارك. |
| `currency` | العملة المتفق عليها في التعاملات. تحدد العملة الأساسية لفواتير العميل. |
| `payment_terms` | الفترة المسموح للعميل بالتأخر في الدفع: "30 يوم بعد BL"، "50% مقدم"، "LC". |
| `credit_limit` | الحد الأقصى للمستحقات غير المحصّلة المسموح للعميل بها. (مُعرَّف لكن غير مُفعَّل كـ validation حالياً) |

---

### suppliers — الموردون

| العمود | الشرح البيزنسي |
|-------|-------------|
| `type` | يُفرق بين: `مورد خام زراعي` (مزارع تورّد خاماً) و`مورد بضاعة جاهزة` (مصانع تورّد منتجاً نهائياً) و`مورد مستلزمات` (يورّد كراتين وتغليف). هذا التصنيف يؤثر على القيود المالية. |

---

### treasury_accounts — الخزينة والبنوك

| العمود | الشرح البيزنسي |
|-------|-------------|
| `balance` | الرصيد الحالي. يتغير مع كل عملية تحصيل أو سداد. هذا رصيد ديناميكي في الكود. |
| `currency` | عملة الحساب. بعض الحسابات بالـ EUR للتحصيل من العملاء الأوروبيين مباشرة. |

---

### contractors — المقاولون

| العمود | الشرح البيزنسي |
|-------|-------------|
| `tariff_rate_per_kg` | السعر المتفق عليه بالجنيه المصري لكل كيلوجرام من المنتج الجاهز. هذا هو أساس احتساب أتعابه في كل عملية إنتاج. |
| `station` | المحطة التي يعمل فيها بشكل أساسي. يُستخدم في اختيار المقاول الافتراضي عند اختيار المحطة. |
