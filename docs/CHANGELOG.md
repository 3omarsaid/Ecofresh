## [v1.1.0-SPEC] - 2026-09-03 (الهندسة الذرية: 26 مايلستون مع Prisma ORM و 5 بوابات تفتيش)

### Added (إضافات الخطة الذرية وبوابات الفحص)
- **تقسيم ذري إلى 26 مايلستون (01 إلى 26):** تقسيم المشروع إلى 26 وحدة عمل مركزة ومنعزلة تناسب النماذج اللغوية الاقتصادية (Junior/Cheap LLMs) بحيث يحتوي كل مايلستون على ملف أو ملفين فقط.
- **5 بوابات تفتيش كبرى (5 Major Quality Gates):**
  1. Major Checkpoint 1 (نهاية M02): التأسيس والمصادقة والواجهة الموحدة.
  2. Major Checkpoint 2 (نهاية M11): البيانات الأساسية والتوريد وطلبيات التصدير وقيد AP.
  3. Major Checkpoint 3 (نهاية M17): تشغيل خطوط الإنتاج والتدوير والمخازن والتحويلات والهالك.
  4. Major Checkpoint 4 (نهاية M23): الشحن والتصدير والربحية اللحظية وفواتير AR والخزينة ودفتر الأستاذ.
  5. Major Checkpoint 5 (نهاية M26): التقارير الاستراتيجية ومحرك PDF وتصدير Excel واختبار E2E والتسليم النهائي.
- **تكامل رسمي لـ Prisma ORM مع Supabase:** كتابة كافة الـ Server Actions والـ Mutations باستخدام `prisma.$transaction` الصارمة لضمان سلامة العمليات التكليفية والمحاسبية.
- **إصلاح الخلل اللوجستي في التحويل بين المحطات (M16):** معالجة الخلل البرمجي القديم في البروتوتايب وضمان خصم المحطة المصدر وإضافة الرصيد للوجهة وتوثيق إذن التحويل.

## [v1.0.0-SPEC] - 2026-09-02 (المواصفات الشاملة للنظام الجديد Next.js + Supabase)

### Added (إضافات المعمارية الجديدة)
- **معمارية الـ Full-Stack الجديدة:** الانتقال الكامل من نموذج البروتوتايب الثابت (Static Prototype) إلى بنية **Next.js 14+ (App Router) + Supabase (PostgreSQL 15)**.
- **عقود واجهات تفصيلية (09-ui-contracts/):** توثيق شامل لـ 59 شاشة مقسمة على 8 ملفات عقود تغطي كل الحقول، المعادلات، وحالات التحقق بالـ Zod.
- **تصميم أمني متكامل (03-architecture/auth-and-permissions-design.md):** ترجمة أدوار البروتوتايب الـ 5 (Admin, Supervisor, Operator, Storekeeper, Viewer) إلى سياسات Supabase Row-Level Security (RLS).
- **سياسات RLS لكل الجداول (04-database/rls-policies.md):** تأمين كل جدول في قاعدة البيانات مع دعم الدوال الذرية (Atomic Security Definer Functions).
- **مخطط قاعدة بيانات وبنوك Postgres (04-database/database-schema.md):** 21 جدولاً علائقياً تشمل القيود والمفاتيح الأجنبية والفهارس وسجل التدقيق الزمني `audit_log`.
- **تصميم الـ Server Actions والـ Route Handlers (05-api/):** توثيق كامل للـ Mutations الذرية مثل `create_shipment_atomic` و `add_raw_material_arrival`.
- **مواصفات ميزات الذكاء الاصطناعي المقترحة (08-ai/):** صياغة البرومبتات وهياكل JSON ونماذج الرؤية الحاسوبية لقراءة تذاكر الميزان البسكول وتحليل جودة الثمار والتنبؤ بالهالك.
- **دليل المستخدم النهائي (docs/CLIENT_USER_MANUAL.md):** دليل تشغيلي شامل يشرح سير العمليات لكل موظف وعامل بالمحطة.
